# 🚗 Pickup Minecraft

Un jeu 3D style Minecraft, en HTML + JavaScript avec Three.js, fait pour un enfant de 9 ans.

## 🎮 Jouer

Ouvre simplement le fichier `voiture3d.html` dans un navigateur.
Three.js est chargé via CDN : il faut juste une connexion internet.

## 🕹️ Commandes

| Touche | Action |
|--------|--------|
| ⬆️ | Avancer |
| ⬇️ | Freiner / reculer |
| ⬅️ ➡️ | Tourner |
| Espace | Klaxon (canard) 🦆 |

## 🛠️ Modifier le jeu

Tout le code est dans `voiture3d.html`, découpé en sections commentées :

1. Scène, caméra, lumières
2. La route (surélevée avec accotements)
3. Le décor (arbres, maisons)
4. La voiture (pickup + creeper en armure d'or)
5. La conduite
6. Le klaxon canard

Chaque section est marquée par `/* ---------- N. ... ---------- */` dans le fichier.
